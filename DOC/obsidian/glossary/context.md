# Context

PIT runtime settings containing a [log level](log-level.md), [trace level](trace-level.md), timing flag and output-module list. Named contexts store reusable choices.

This is distinct from the Oracle application-context storage mechanism. PIT can use global context support or local session state; visibility depends on the installation and configuration.
