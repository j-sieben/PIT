# Output module

An instantiable subtype of `PIT_MODULE` that implements delivery to a destination such as tables, the console, a file, mail or APEX.

Installation, runtime availability and selection in a [context](context.md) are separate states. The inherited base methods do nothing unless overridden.

Continue with [output modules](../output_modules.md).
