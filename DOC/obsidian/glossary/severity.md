# Severity

The importance assigned to a [message](message.md). Smaller numeric values mean more severe messages.

The current scale is fatal 10, severe 20, error 30, warn 40, info 50, debug 60 and all/verbose 70. A severity belongs to a message; a [log level](log-level.md) controls admission.
