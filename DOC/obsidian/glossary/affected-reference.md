# Affected reference

An identifier for an object or field related to a [message](message.md), passed through `p_affected_id` or the named `p_affected_ids` collection.

These references do not replace text arguments or trace [parameters](parameter.md). PIT_TABLE stores them in `PIT_TABLE_PARAMS`, linked to the parent message ID.

Continue with [output modules](../output_modules.md).
