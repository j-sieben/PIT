# Error stack

The Oracle error [messages](message.md) available for the currently handled [exception](exception.md), including their error numbers.

`pit_util.get_error_stack` formats all those messages and then appends the [exception backtrace](exception-backtrace.md). Its optional filter applies to backtrace units only, not to the error messages.
