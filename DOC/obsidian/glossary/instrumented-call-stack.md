# Instrumented call stack

The hierarchy PIT maintains using application entry and exit calls.

It supports trace output, [parameter](parameter.md) capture, timing, [context](context.md) restoration and long-operation state. It is separate from an Oracle [dynamic stack](dynamic-call-stack.md) snapshot.
