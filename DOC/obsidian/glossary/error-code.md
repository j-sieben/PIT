# Error code

An application-defined identifier carried by `MESSAGE_TYPE.ERROR_CODE`, independent of the Oracle [exception](exception.md) number.

It distinguishes several uses of one [message](message.md), groups related validations and supports UI mapping. During collection, an omitted code defaults to the message name.
