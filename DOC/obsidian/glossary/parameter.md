# Parameter

A named, typed configuration value within a parameter group. PIT uses the reusable parameter framework for its own settings.

Use `PARAM` for effective values and local overrides, and `PARAM_ADMIN` for definitions, groups, [realms](realm.md) and exports. These configuration values are distinct from PL/SQL formal parameters and [message arguments](message-argument.md).
