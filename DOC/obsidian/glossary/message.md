# Message

A named text definition used by PIT for logging, [exceptions](exception.md), validation or presentation. It belongs to a [message group](message-group.md), has a [severity](severity.md) and has text in the default language, with optional translations.

The generated `MSG` package contains the message-name constant. Runtime construction creates a `MESSAGE_TYPE` with resolved text, arguments and environment information.
