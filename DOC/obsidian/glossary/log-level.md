# Log level

A numeric threshold used by a [context](context.md) to control ordinary [message](message.md) logging. A larger value admits more detail.

Error, severe and fatal logging is admitted by the runtime even with a lower context threshold. An available [output module](output-module.md) and its channel-specific rules are still required for delivery.
