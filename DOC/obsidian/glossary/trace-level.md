# Trace level

A threshold controlling which instrumented entry and exit calls are tracked. It is a separate scale from [message](message.md) [severity](severity.md).

Values are off 10, mandatory 20, optional 30, detailed 40 and all 50. Use matching entry and exit variants so the stack remains balanced at each configured threshold.
