# Context toggle

A rule that switches PIT settings when an instrumented package or method is entered and restores the preceding settings on exit.

A toggle references a named [context](context.md) and requires `ALLOW_TOGGLE`. Tracking toggles can require minimal stack maintenance even when normal trace output is disabled.

Continue with [handling contexts](../handling_contexts.md).
