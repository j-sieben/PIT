# Translatable item

Application text maintained by PIT with a stable item ID and group, separate from an [exception](exception.md) or log [message](message.md).

Each language row supplies a name, display name and description. Runtime access uses the published materialized view and an effective-language session view, with fallback when a translated row is absent.
