# Fire threshold

A module-level [severity](severity.md) threshold used to restrict the [messages](message.md) that destination processes.

The usual comparison is message severity less than or equal to the threshold. Each channel implementation decides whether to apply it; do not infer trace or tweet behavior from [exception](exception.md) logging alone.
