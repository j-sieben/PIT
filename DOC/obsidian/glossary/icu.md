# ICU

The optional Java-backed [message](message.md)-formatting integration used for language-sensitive selections, plurals and formatted values.

Select it by passing `pit.format_icu` as the first [message argument](message-argument.md). Named values can be supplied as JSON. Required Java classes must be installed and resolved in the database.

Continue with [icu messages](../icu_messages.md).
